## 平台实际动作边界

- BOSS支持经过明确页面证据配置的沟通文字流程；当前没有经过验收的本地PDF附件上传链路。
- 猎聘投递平台侧简历。审核页先读取平台简历ID/摘要，执行前再次核对；不冒充发送了本地PDF。
- 本地简历JSON内容哈希与实际PDF文件哈希已区分。
- 平台错误、模糊结果、网络中断不自动标记成功；外部提交未知结果先核对。
- 默认仍不启用真实发送。MCP工具Schema、DOM选择器、城市编码和账号权限需现场核实。
- 多城市/分页代码已加入，仍需以实际平台能力验证参数和返回内容。

## BOSS自动投递补全

- 增加独立真实Runner启动开关，测试模式和真实模式不会静默混用。
- BOSS搜索结果逐条进入详情页读取完整JD、公司、岗位和薪资，再交给匹配服务。
- 增加详情请求间隔抖动、每页最大岗位数和空结果识别，避免无限空转。
- 登录、验证码、当日沟通上限和职位下线分别进入可解释人工处理状态。
- 职位发现支持长时间后台运行和刷新恢复；部分完成会保留岗位、城市/页码进度及中断原因，一条龙在登录或验证码中断时暂停而不发送。
- BOSS登录探测采用已登录/明确退出/暂时未知三态，CDP和接口短暂异常不会直接生成人工登录任务。
- 一条龙执行任务误报登录中断时，后台会自动重连并最多复核三次；确认会话和账号指纹后自动重排原任务并恢复一条龙，明确退出、验证码和账号不匹配仍要求人工处理。
- 内置版本化选择器候选，并保留环境变量覆盖；页面契约变化时拒绝发送而非猜测成功。
- BOSS招呼语限制为1至100字符，根据岗位和已匹配技能生成，审核页支持重新生成和手工核对。
- 增加设置页BOSS诊断，显示浏览器、登录和城市编码配置是否就绪。
- BOSS审核动作已扩展为“发起沟通、发送已审核招呼语、选择平台简历并确认发送”；只有聊天区出现简历卡片才记为成功。
- 默认选择BOSS账号中的第1份平台简历，支持通过BOSS_RESUME_INDEX和选择器环境变量覆盖；本地PDF不会冒充平台附件。
- 平台简历发送代码与回执保护已完成，仍需用户登录后做一次真实单岗位现场验收。

## 需要外部配置或进一步增强的部分

- Docker Desktop启动已尝试，但本机引擎仍未提供可用API；PostgreSQL运行验收待环境恢复。
- 在线Provider需LLM_MODE、LLM_BASE_URL、LLM_API_KEY、LLM_MODEL。未用用户真实密钥做外部调用。
- Runner配对需Core配置稳定的RUNNER_ENCRYPTION_KEY；设备凭据不返回前端。
- OCR、DOCX导出、完整复杂文档语料、人工招聘标注集及规模化生产负载评测尚未完成。
- 多租户Runner池、复杂跨平台自动聊天不在当前个人版交付范围。
- JSON业务恢复刻意不恢复登录/设备秘密、活动Outbox及文件二进制；完整灾备需要数据库与artifacts目录一起备份。
- 没有通过新增假简历、假岗位或假回执填充日常工作区。

## 简历自动识别完善

- TXT、PDF文本层与DOCX提取结果进入统一字段结构器。
- 自动识别姓名、求职方向、邮箱、手机号、城市和个人主页。
- PDF中存在可用照片时自动导入头像；按章节拆分多条教育、工作/实习/在校经历、项目、优势、技能、证书、语言能力和其他内容。
- 识别学校、专业、学历、公司、岗位/角色、项目名称、时间、说明和成果条目。
- 支持中文/英文标题、显式键值标签、常见时间范围、项目符号和Word表格单元格。
- 支持PDF文本层将“项目经历”和首个项目名粘在同一行的情况，并保留该项目的名称、时间、角色和亮点。
- 每个自动字段保存原文、字符位置、页码和置信度，编辑器提供核对入口。
- 已导入简历可用保存的原文重新识别；重新识别只更新草稿修订，不覆盖已发布历史版本。
- 导入结果保持待确认状态，用户确认前不会发布为正式版本或参与正式匹配。
- 识别不确定的内容保留在说明和sourceText中，不编造不存在的学校、公司或经历。
- 复杂双栏、扫描PDF及非标准模板仍需用户核对；扫描PDF需要OCR。

# BOSS后台执行与筛选增强（2026-09-09）

- Runner接管BOSS专用浏览器生命周期；`auto`模式使用最小化的正常浏览器，首次登录或验证码时恢复可见窗口。
- 保留显式`headless`实验模式。真实账号验收中BOSS返回36/37风控，因此不将纯headless设为默认。
- 岗位发现增加包含词命中数、排除词、排除公司、薪资、招聘者活跃度、猎头、最大结果数、同公司及同招聘者冷却过滤。
- 新增Dry-run执行策略，只完成已批准岗位的页面身份预检，不进入签名和提交阶段。
- BOSS提交增加随机间隔、批次暂停，以及页面内`friend/add.json`接口兜底；达到平台频率或每日沟通限制时暂停。
- 继续保留单次审批证明、幂等命令、未知结果核对和消息/简历证据验证，不以HTTP 200直接认定投递成功。
- 增加岗位文本风险提示、公司规模、招聘者活跃度、同公司/同招聘者历史次数和CSV导出。
- 增加高德Web服务通勤距离/时间过滤；Key仅从Runner环境读取。
- 增加独立BOSS profile创建、切换和当前配置持久化；不同配置不共享Cookie。
- 增加轻量浏览器扩展浮动面板，作为职位发现、审核、执行和设置入口，不复制发送逻辑。
